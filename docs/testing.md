本番プレビューの確認中、Vite の `Vary: Origin` ヘッダーにより、プリキャッシュとブラウザの module リクエストで Origin が異なるとキャッシュに一致せず、オフラインで画面が空白になる問題を発見しました。正確に列挙した同一オリジンの静的ファイルだけ、`ignoreVary: true` で一致させるよう修正し、再発防止テストを追加しました。また、HTML を有効な Service Worker のキャッシュから優先して提供し、利用者が新しい版を有効にするまで HTML と JS の組を保つテストも追加しています。修正後の実ブラウザの結果は最終確認に記録します。
